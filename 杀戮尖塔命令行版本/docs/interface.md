# 网页命令界面

视觉方向：深炭色终端、暖白文字和克制的暗红与铜色强调；以清晰的战况阅读和键盘输入为中心。
内容布局：顶部游戏标题与连接状态；主区固定敌人信息、手牌和命令栏，中间滚动显示规则消息和事件；命令历史暂时隐藏，记录仍保存在当前标签页供后续恢复。侧栏显示角色状态、遗物和命令速查。顶部阶段显示“第 X/3 幕”，总幕数来自原版 `RunState.Acts.Count`。敌人意图使用原版标签及可用的本地化标题/说明；原版隐藏提示的意图保持隐藏。怪物增益/减益使用原版 Power 悬浮说明及动态数值文本展示。Boss 战额外显示原版遭遇标题；Boss 奖励结算完成后显示“进入下一幕”按钮，调用原版 `RunManager.EnterNextAct()`；第三幕则进入原版终局事件。战斗快照优先使用原版 CombatManager 的敌人集合，意图贴图缺失时仍保留名称和 HP。战斗手牌采用有间距的双列布局，卡牌高度、列距和中文说明行距适当放宽，描述单行截断并保留完整悬停提示；战斗中手牌直接点击即可提交 `play`，需要 `AnyEnemy` 或 `AnyAlly` 目标的卡牌先高亮目标选择，再提交带目标编号的同一内置命令；命令框仍可手动操作。敌人面板独立滚动，避免被日志挤走。
地图视图使用原版地图节点及 `MapPoint.Children` 连线，以全屏路线页展示原版提供的后续路线和 `VisitedMapCoords` 行程。增加节点行距，SVG 按地图内容高度绘制；地图画布支持滚轮、触屏和键盘滚动，标题与路线工具保持可见。SVG 手绘层视觉上位于节点和路线之上；普通查看时笔迹不拦截节点点击，只有擦除模式会命中笔迹。手绘、擦除和清空仅为当前浏览器标签页内的规划标注，不执行游戏操作。可达地图节点和路线按钮点击后立即提交对应的 `move` 内置命令；命令框手动执行 `move` 时也会先收起已打开的路线页，避免遮住新房间的选项。运行时还等待原版地图投票后续的目标房间真正进入，再发布 `move` 的快照，避免未完成的 `MapRoom` 过渡帧覆盖问号或休息处。事件快照额外提供原版初始化/完成状态 `eventState.initialized/finished/optionCount`，休息处提供 `restState.initialized/actionCompleted/optionCount/enabledCount`；事件、问号事件、休息处和宝箱在原版选项或结算尚未完成时强制收起自动地图，先显示交互。事件完成后保留事件结果和路线清单，用户可点击“查看地图”或路线按钮再打开/前进；手动执行 `map` 仍可打开全屏路线图。原版卡牌变化记录也会在事件结算消息中显示实际的原卡与新卡。商店优先显示商品和可达路线清单，并提供“查看地图”按钮；房间未完成或原版动作仍在结算时，网页和文字地图只显示路线预览。
事件、休息处、宝箱、奖励、商店和单选选项点击后立即提交快照对应的内置命令；商店额外提供原版 Proceed 对应的“离开商店”按钮，点击后直接打开路线图。进入宝箱先点击“开启宝箱”，开启后再点击原版遗物或跳过。命令框仍可用于手动操作。原版多选会显示范围，点选卡牌以加入/移出待选列表，再点击“确认选择”提交组合 `choose 编号 编号`。只在原版 `CardSelectorPrefs.Cancelable` 的铁匠、烹饪、商店移除和移除奖励选牌中提供“取消选牌”；其它强制选择不显示取消入口。命令历史暂时隐藏但仍保留当前标签页记录。
交互方向：状态更新短暂淡入；新日志顺序出现；输入焦点和发送状态平滑过渡；减少动态效果时禁用这些动画。地图工具支持鼠标和触摸；关闭按钮或 Escape 收起地图，并恢复文字路线清单。

所有推进动作最终经网页内置命令提交，点击手牌、敌人、角色、选项或路线只是提交对应命令的快捷入口；规则校验仍在 Python HTTP 桥和原版程序集侧完成。既不使用浏览器开发者控制台，也不依赖用户打开系统终端游玩。网站服务启动属于安装运行步骤。
