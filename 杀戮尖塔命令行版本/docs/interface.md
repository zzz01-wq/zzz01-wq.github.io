# 网页命令界面

视觉方向：深炭色终端、暖白文字和克制的暗红与铜色强调；独立操作按钮默认使用可辨识的强调色、底色或边线，不以悬停作为唯一提示；事件、奖励等整行选择继续使用紧凑分隔列表，避免整行铺色；禁用控件保持弱化，只有用户明确要求时才将可用按钮改为低调样式。优先用点击开始、选择角色与房间选项，命令框作为可选操作入口。
开局：主菜单按钮只显示原版按钮名称，不加自拟副标题。有可继续存档时只显示“继续游戏”和“放弃当前游戏”，单人模式入口隐藏；确认放弃后按原版流程记录失败与历史，再回到可开始新旅程的菜单。旅程进行中右侧栏的“放弃”会调用原版 `RunManager.Abandon()`；TestMode 下角色死亡后由宿主补调同一原版 `RunManager.OnEnded(false)`，确保失败局进度与历史落盘。没有存档时显示单人模式；原版首次运行会直接进入角色选择，已有已结束旅程时先进入标准、每日挑战、自定模式选择。模式页的标题、说明与 Daily/Custom 锁定说明由原版 `main_menu_ui.json` 和 `SaveManager.IsEpochRevealed<T>()` 生成，标准模式进入角色选择。网页已接入原版控制的时间线和百科：时间线展示存档中的 Epoch，并按原版状态支持揭示或查看详情；时间线按原版 `EpochEra` 与 `EraPosition` 放置节点，保留时代内空位，不绘制 Epoch 间连线，节点下方显示横向时代轴和刻度；简中原版未提供部分非 0 Era 的名称/年份，前端隐藏这些空标题栏但保留节点列位。普通启动停留在开始菜单，不自动打开时间线；存在真实待揭示节点时按原版限制开始新旅程和百科入口，并在全部揭示前禁用返回；没有待揭示节点时可手动查看时间线。百科按原版可用条件打开卡牌、遗物、药水、怪物、统计和历史分区，条目名称、说明与发现/解锁状态来自原版模型、本地化和进度。页面采用文字时代栏、列表和详情布局，不加载原版图像与动画；Run History 目前是摘要页而非原版逐层地图/牌组交互，也不代表完整 1:1。Daily、Custom、多人、设置与退出仍未接入。角色选择页可玩角色资料取自原版 `CharacterModel`；未解锁角色严格使用原版角色选择屏的锁定分支：显示“锁定”、`CharacterModel.GetUnlockText()`、隐藏属性占位值及“未知遗物”，不显示静默猎手名字、简介、真实属性/遗物或时间线节点条件，也不提供启程操作。命令 `unlock silent` 保留作点击时间线的兼容入口。命令框仍是可选操作入口。
内容布局：顶部游戏标题与连接状态；主区固定敌人信息、手牌和命令栏，中间用于事件、房间选项与路线。命令回显历史区已移除；命令消息不再通过顶部悬浮层显示。事件变牌结果以及真理石板实际升级的牌名显示在对应事件区域。命令历史暂时隐藏，记录仍保存在当前标签页供后续恢复。开始菜单且没有在途角色时隐藏右侧栏；旅程开始后右侧栏显示角色状态、遗物及“查看地图”按钮，不显示命令速查；旅程进行中在右侧栏提供原版“放弃”文案的入口，确认框使用原版本地化，确认后执行现有原版放弃结算路径。原版入口实际位于暂停菜单；网页将它放在右侧栏，不表示暂停菜单已完整实现。顶部阶段显示“第 X/3 幕”，总幕数来自原版 `RunState.Acts.Count`。角色与怪物身上的增益、减益和状态都使用原版 Power 标题、类型、动态数值和格式化后的具体效果说明；不把通用数值自行解释为回合数。Boss 战额外显示原版遭遇标题；Boss 奖励结算完成后显示“进入下一幕”按钮，调用原版 `RunManager.EnterNextAct()`；第三幕则进入原版终局事件。建筑师终局事件显示原版按角色/胜场选取的当前说话人和对白；逐句按钮沿用原版 `.next` 文案和 `EventOption` 回调，末句由原版胜利流程处理。TestMode 下首句选项的恢复方式及验证边界见 `docs/sources.md`，不代表复刻原版对白气泡、攻击演出或完整终局。战斗快照优先使用原版 CombatManager 的敌人集合，意图贴图缺失时仍保留名称和 HP。卡牌类型直接使用原版 `CardType.ToLocString()` 的简体中文标签，并与卡名同行显示；选牌名称与描述共用对齐基线。原版 `CardModel.HoverTips` 提供特殊词条提示；网页将对应描述词条标为下划线，鼠标悬停或键盘聚焦时立即显示自定义提示框，使用原版标题和说明，并在视口边缘调整位置，不触发浏览器原生 `title` 气泡。卡牌奖励和选牌说明直接显示在当前选项列表中；命令反馈不使用悬浮层，错误信息留在命令栏上方状态行。战斗手牌采用有间距的双列布局，卡牌高度、列距和中文说明行距适当放宽，描述单行截断并保留完整悬停提示；战斗时手牌区顶部提供“结束回合”按钮（即使手牌为空也显示），点击提交现有 `end` 命令并由原版 `EndPlayerTurnAction` 结算。需要目标的卡牌先高亮目标选择，再提交带目标编号的内置出牌命令。原版历史中标记为自动打出的玩家卡牌会在敌人区下方列出名称，战斗结束后保留在当前地图节点，离开该节点后清除。敌人面板独立滚动。地图和敌人意图弹窗只保留中文标题，不再显示 `ROUTE MAP`、`ENEMY INTENT` 英文眉题。已开放的事件选项不在提示行重复列出 `choose 编号` 和 `map 预览路线`；点击选项与查看地图入口仍保留，命令框继续可选。

偷窃草蜢触发偷盗后，在对应敌人信息下显示原版 `SwipePower.StolenCard` 的实际牌名；点击牌名可打开卡牌详情。战斗奖励中，被偷的牌以原版特殊卡牌奖励出现，可先查看牌面，再选择“取回”或“返回奖励列表”。返回列表不会改变奖励状态；如决定不取回，可在奖励列表使用“跳过剩余奖励”，由原版奖励同步器处理未领取奖励。

水晶球事件在选择原版服务方案后，当前选项区显示原版本地化占卜说明、工具选择和 11×11 可点击格子。点按格子/工具按钮会提交 `scry 列 行` / `scry small|big` 内置命令；悬停格子会按原版 `SetHoveredCell()` 的 Small/Big 范围预览清格区域，网页不展示未揭开的物品。每次点击扣除次数、清格、揭示物品和最终奖励都由原版 `CrystalSphereMinigame` 与奖励同步器执行；占卜期间保留事件阶段，避免自动切回地图。原版会用逐格遮罩揭开物品纹理；网页目前只显示完整揭示的物品标签，不复刻其纹理碎片和动画，因此这里只接入原版规则调用，不声称图形界面或完整玩法 1:1。
地图视图使用原版地图节点及 `MapPoint.Children` 连线，以全屏路线页展示原版提供的后续路线和 `VisitedMapCoords` 行程。增加节点行距，SVG 按地图内容高度绘制；地图画布支持滚轮、触屏和键盘滚动，标题与路线工具保持可见。SVG 手绘层视觉上位于节点和路线之上，但笔迹始终不接收指针事件；绘制/擦除模式下点击可达节点仍会执行路线选择。绘制仅从空白地图区域开始，擦除通过笔迹附近位置识别，节点点击优先，不让笔迹覆盖节点的点击目标。手绘、擦除和清空仅为当前浏览器标签页内的规划标注，不执行游戏操作。可达地图节点和路线按钮点击后立即提交对应的 `move` 内置命令；命令框手动执行 `move` 时也会先收起已打开的路线页，避免遮住新房间的选项。运行时还等待原版地图投票后续的目标房间真正进入，再发布 `move` 的快照，避免未完成的 `MapRoom` 过渡帧覆盖问号或休息处。事件快照额外提供原版初始化/完成状态 `eventState.initialized/finished/optionCount`，休息处提供 `restState.initialized/actionCompleted/optionCount/enabledCount`；事件、问号事件、休息处和宝箱在原版选项或结算尚未完成时强制收起自动地图，先显示交互。事件完成后保留事件结果，并显示原版“继续”选项；点击后打开路线图，也可使用右侧“查看地图”按钮，随后点击地图节点前进；手动执行 `map` 仍可打开全屏路线图。原版卡牌变化记录也会在事件结算消息中显示实际的原卡与新卡。商店优先显示商品；右侧侧栏提供“查看地图”按钮，路线在地图覆盖页中显示；房间未完成或原版动作仍在结算时，路线节点保持预览状态且不可前往。
事件、休息处、宝箱、奖励、商店和单选选项点击后立即提交快照对应的内置命令；商店额外提供原版 Proceed 对应的“离开商店”按钮，点击后直接打开路线图。进入宝箱先点击“开启宝箱”，开启后再点击原版遗物或跳过。命令框仍可用于手动操作。原版多选会显示范围，点选卡牌以加入/移出待选列表，再点击“确认选择”提交组合 `choose 编号 编号`。只在原版 `CardSelectorPrefs.Cancelable` 的铁匠、烹饪、商店移除和移除奖励选牌中提供“取消选牌”；其它强制选择不显示取消入口。命令历史暂时隐藏但仍保留当前标签页记录。旅程中右侧药水槽显示原版药水名称、动态说明与当前可用状态；可用药水可直接点击使用。需要指定敌人的药水先点击槽位进入目标选择，再点击敌人执行；具体时机、目标、可用性与效果仍由原版药水模型及 `UsePotionAction` 校验结算。
交互方向：状态更新短暂淡入；错误提示显示在命令栏上方的状态文字中，不使用弹出层；输入焦点和发送状态平滑过渡；减少动态效果时禁用这些动画。地图工具支持鼠标和触摸；关闭按钮或 Escape 收起地图，并恢复文字路线清单。

所有推进动作最终经网页内置命令提交，点击手牌、敌人、角色、选项或路线只是提交对应命令的快捷入口；规则校验仍在 Python HTTP 桥和原版程序集侧完成。既不使用浏览器开发者控制台，也不依赖用户打开系统终端游玩。网站服务启动属于安装运行步骤。

水晶球占卜次数耗尽后，原版揭示的诅咒已直接加入牌组，金币、药水、卡牌和遗物等奖励进入原版奖励领取流程。领取界面出现时网页收起已结束的占卜棋盘，并将滚动位置移回奖励选项；该布局适配只改变网页展示，不改变原版奖励与跳过逻辑。

牌组与事件牌面：右侧“卡组”数量可点击，打开当前 `Player.Deck.Cards` 列表，并在同一面板查看选中卡牌的类型、能量、原版描述及特殊词条提示。事件选项只有在原版 `EventOption.HoverTips` 实际含有 `CardHoverTip` 时，才会将选项文本中的卡名标为下划线；特殊卡牌奖励也直接将卡名标为下划线。点击卡名打开原版卡牌详情，不选择事件，也不改变牌组或奖励状态。选项文本未提到卡名时，在说明下显示可点击的卡名；不额外增加“查看牌面”按钮。选中项高亮增加左右内边距，避免文字贴边。

休息处铁匠选牌按原版提供“查看升级”切换；开启后，候选牌展示原版克隆卡的升级后名称、费用、说明和关键词。点击单张候选牌先打开“升级前/升级后”对照，确认后才提交原版 choose；取消或关闭预览会返回选牌列表，不修改牌组。一次选择多张时也会先展示所有升级前后对照再确认。
