# 网页命令界面

视觉方向：深炭色终端、暖白文字和克制的暗红与铜色强调；以清晰的战况阅读和键盘输入为中心。
内容布局：顶部游戏标题与连接状态；主区固定敌人信息、手牌和命令栏，中间滚动显示规则消息和事件；已提交命令单独放入可滚动的命令历史栏，点击历史项只会填入命令框，不会自动执行。侧栏显示角色状态、遗物和命令速查。敌人意图使用原版标签及可用的本地化标题/说明；原版隐藏提示的意图保持隐藏。怪物增益/减益使用原版 Power 悬浮说明及动态数值文本展示。战斗手牌采用紧凑双列，描述单行截断并保留完整悬停提示；敌人面板独立滚动，避免被日志挤走。小屏幕的命令历史默认收起，避免压缩战况区。
地图视图使用原版地图节点及 `MapPoint.Children` 连线，以全屏路线页展示原版提供的后续路线和 `VisitedMapCoords` 行程。增加节点行距，SVG 按地图内容高度绘制；地图画布支持滚轮、触屏和键盘滚动，标题与路线工具保持可见。SVG 手绘层位于节点和路线之上；手绘、擦除和清空仅为当前浏览器标签页内的规划标注，不执行游戏操作。可达地图节点和路线按钮点击后立即提交对应的 `move` 内置命令；命令框手动执行 `move` 时也会先收起已打开的路线页，避免遮住新房间的选项。进入休息处时优先显示营火行动；所有行动选择完成后再按路线逻辑打开地图。房间未完成或原版动作仍在结算时，网页和文字地图只显示路线预览。
事件、休息处、宝箱、奖励、商店和单选选项点击后立即提交快照对应的内置命令，命令框仍可用于手动操作。原版多选会显示范围，点选卡牌以加入/移出待选列表，再点击“确认选择”提交组合 `choose 编号 编号`。只在原版 `CardSelectorPrefs.Cancelable` 的铁匠、烹饪、商店移除和移除奖励选牌中提供“取消选牌”；其它强制选择不显示取消入口。命令历史项仍只填入命令框，避免误执行旧命令。
交互方向：状态更新短暂淡入；新日志顺序出现；输入焦点和发送状态平滑过渡；减少动态效果时禁用这些动画。地图工具支持鼠标和触摸；关闭按钮或 Escape 收起地图，并恢复文字路线清单。

全部游戏操作经网页内置命令提交，既不使用浏览器开发者控制台，也不依赖用户打开系统终端游玩。网站服务启动属于安装运行步骤。
