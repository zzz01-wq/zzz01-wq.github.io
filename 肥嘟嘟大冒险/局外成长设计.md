# 骑手基地 · 局外成长

## 设计依据

[《ZERO Sievert》官方生存指南](https://shared.fastly.steamstatic.com/store_item_assets/steam/apps/1782120/manuals/adca8b959cf66c1e8dfcb562cee73fafb9fe1672/ZS_Survival_Guide_1.0_English.pdf?t=1754396954)介绍通过储存模块和部分任务扩充仓库；[《ARC Raiders》第二次远征官方说明](https://arcraiders.com/news/second-expedition-rewards-and-requirements)也将额外仓库空间列为永久奖励。

本作借鉴的是“撤离收益换取永久容量与功能成长”的循环。上述游戏的仓库容量与本作随身背包不是同一种容量；本作目前撤离即自动变卖，所以优先扩充能直接影响搜刮取舍的随身背包。搜索、侦察和回收商加成是针对当前玩法提出的适配设计，数值仍需实战调优。

- 只在备战室购买，立即存档，永久效果在后续对局中生效；阵亡不损失已有升级。
- 界面展示当前效果、下一等级效果、价格、余额缺口和满级状态。
- 背包每件物品一格，不叠放；所有拾取、卸下、搜箱及满包判断共享实际容量。
- 搜索升级按比例减少每格耗时，不改变高品质物品更慢的顺序。满级白色约 0.49 秒，红色 7.6 秒。
- 侦察仅改变小地图显示敌人的距离，不改变敌人 AI，也不改变场景中角色的可见距离。
- 撤离收益为实际携带物品总估值 + 向下取整的回收商加成。背包物资和已装备外卖均计入；失败无本局收入，结算不可重复领取。
- 延用 `fdd-extraction-v1` 存档键，旧饭票和三条原有升级保留，新增升级从 0 级开始。不同浏览器或访问地址仍不共享存档。

## 后续可扩展，尚未实现

建议先观察几局真实收益与背包满载率，再调整价格。当前背包第一档定价较低，让玩家尽快体验撤离后的成长；后续成本递增，保留连续出局的动力。

如果进一步加入跨局物资仓库，再增加“保留 / 出售”结算选择、材料升级配方与委托任务，让高价值物品以外的普通物资也有保留理由。仓库扩容应与随身背包扩容分别购买。安全箱可后续做少量格子的功能解锁，但需要先明确哪些物品允许保底带出，以及是否影响搜打撤的损失压力。
