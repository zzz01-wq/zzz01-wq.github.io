# 肥嘟嘟大冒险 · 外卖大乱斗

双击 `index.html` 用支持 WebGL 的现代浏览器打开。HTML 内嵌 Three.js 和生成主视觉，无网络依赖。

手机局域网测试：电脑安装 Node.js 18 或以上，在项目目录运行 `npm run dev`（无需安装依赖），再用同一 Wi-Fi 下的手机打开终端输出的“手机”地址。默认端口为 5173，可通过 `PORT=其他端口 npm run dev` 修改。服务监听 `0.0.0.0`，刷新页面即可看到最新修改。

- WASD / 方向键移动；手机或鼠标按住战场拖动。
- 空格 / 冲刺按钮加速，冷却 4 秒，冲刺期间免疫身体伤害。
- 六类外卖：可乐、汉堡、薯条、螺蛳粉、面条、炒饭。
- 外卖自动环绕。同级碰撞双方抵消，高级抵消低级后降一级。
- 拾取同款同级合成，最高三级，最多携带 12 份。
- 身体被击中三次即出局；击败对手掉落剩余外卖。
- 每 10 点经验升一级并恢复一点体力，坚持 180 秒获胜。
- P 暂停；点击开始游戏时默认启用音效，右上角扬声器按钮可切换静音。拾取使用上扬双音提示，外卖互撞使用真实刀剑碰撞录音（三个随机变体，带距离衰减和叠音限制）；冲刺和击败使用合成提示音。刀剑素材已内嵌 HTML，离线可用，来源见 `assets/audio/CREDITS.md`。

美术：开场使用内置 image_gen 生成的主视觉 `assets/key-art-v2.png`；实际游戏角色和外卖为程序构建的简化 3D 模型，并非效果图等精度模型。

验证：通过 JavaScript 语法检查，以及移动、合成、同级抵消、高级降级、身体命中、击败掉落、冲刺、暂停、限时结算、重开和连续模拟逻辑测试。当前工具无可连接浏览器，尚未完成浏览器画面及真机触控验收。
