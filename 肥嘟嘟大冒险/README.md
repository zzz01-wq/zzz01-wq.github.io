# 肥嘟嘟大冒险 · 美食街搜打撤

单 HTML 3D 游戏原型。`index.html` 内嵌 Three.js、生成封面与刀剑音效，可直接离线打开。

## 手机局域网测试

Node.js 18+，无需安装依赖：

```sh
npm run dev
```

同一 Wi-Fi 下，手机打开终端输出的“手机”地址。默认端口 5173，监听 `0.0.0.0`。修改后刷新页面生效。`PORT=其他端口 npm run dev` 可更换端口。

## 搜打撤流程

1. 备战室选择早餐街、夜市巷、物流园或美食广场，确认后播放空投落地动画。
2. 地图为 144 × 112 的矩形街区，约为原圆形竞技场面积的 9 倍，包含道路、16 栋有碰撞的建筑、32 个箱子和 3 个撤离点。
3. 拖动战场 / WASD / 方向键移动。空格或右下角按钮冲刺；P 暂停。
4. 靠近箱子并停止移动 1.25 秒自动搜刮，获得随身货物估值、经验和掉落外卖。移动或受击会打断开箱。
5. 外卖自动绕身攻击；同级互相抵消，高级抵消低级后降一级。同款同级拾取自动合成，最高三级，最多携带 12 份。
6. 每 10 经验升级，在随机三个技能中选择一个：移动、拾取范围、旋转、冲刺冷却、体力或高级外卖。选择时暂停战场，本局技能不跨局保留。
7. 撤离点位于西侧、东侧、南门，小地图上为绿色方块。落地 45 秒后开放，在范围内停止移动 6 秒即可撤离；移动、离开范围或受击会清空进度。
8. 成功撤离将箱子货物与剩余外卖自动换成饭票。阵亡或 6 分钟超时丢失本局收益，永久成长与已有饭票保留。
9. 饭票可购买加厚外卖服（体力）、开局加餐（外卖）和骑手训练（速度），各 3 级。

存档使用浏览器 localStorage，同一访问地址下保留。手机与电脑不共享存档；更换 IP、端口或清除站点数据会使用不同/新的存档。当前是单人原型，敌人为 AI，不包含联机、背包仓库或飞机航线内自由跳伞。

## 美术和音效

- 主视觉：内置 image_gen 生成的 `assets/key-art-v2.png`，提示词在 `assets/image-prompt-v2.txt`。
- 游戏角色和物品：程序化 3D 模型。敌人为奶龙与耄耋参考形象。
- 开局点击按钮启用音效，右上角扬声器切换静音。
- 拾取为上扬双音；物品互撞为真实刀剑录音（三种变体、距离衰减、叠音限制），来源和 CC0 授权见 `assets/audio/CREDITS.md`。
