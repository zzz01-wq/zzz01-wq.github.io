# 肥嘟嘟大冒险 · 美食街搜打撤

单 HTML 3D 游戏原型。`index.html` 内嵌 Three.js、生成封面与刀剑音效，可直接离线打开。

## 手机局域网测试

Node.js 18+，无需安装依赖：

```sh
npm run dev
```

同一 Wi-Fi 下，手机打开终端输出的“手机”地址。默认端口 5173，监听 `0.0.0.0`。修改后刷新页面生效。`PORT=其他端口 npm run dev` 可更换端口。

## 搜打撤流程

1. 备战室选择早餐街、夜市巷、物流园或美食广场，确认后播放空投落地动画。
2. 地图为 144 × 112 的矩形街区，约为原圆形竞技场面积的 9 倍，包含道路、16 栋有碰撞的建筑、32 个箱子和 3 个撤离点。
3. 拖动战场 / WASD / 方向键移动。空格或右下角按钮冲刺；P 暂停。
4. 靠近箱子按 E 或点击“搜索箱子”，打开箱子与背包界面，按格自动搜索。箱子容量按品质在独立范围内随机生成：普通 2–3 格、稀有 4–5 格、史诗 6–7 格、传说 8–10 格、罕见 11–14 格，每格一件物品；外卖与物资混合生成；箱子分五档品质，并保证至少一件同档物品，高级箱的其他物品也更容易出高品质；离开或受击会打断搜索。搜索时战场不暂停，关闭后已经揭示的物品保留，重开不会重置箱子内容。
5. 外卖自动绕身攻击；同级互相抵消，高级抵消低级后降一级。装备同款同品质时合成，最高五档，最多装备 12 份。等级依次为普通（白）、稀有（蓝）、史诗（紫）、传说（橙）、罕见（红），高风险街区有更高概率开出高级物品。
6. 每 10 经验升级，在随机三个技能中选择一个：移动、拾取范围、旋转、冲刺冷却、体力或高级外卖。选择时暂停战场，本局技能不跨局保留。开箱或整理背包期间升级不会弹窗打断：先累计待选技能并显示提示，关闭界面后按升级顺序依次选择，搜索中的进度不会因升级被清空。
7. 撤离点位于西侧、东侧、南门，小地图上为绿色方块。落地 45 秒后开放，在范围内停止移动 6 秒即可撤离；移动、离开范围或受击会清空进度。
8. 按 B 或点击“背包”整理 16 格背包，每件物品占一格、不叠放。单击查看详情；双击（手机快速连点两下）外卖直接装备/合成，双击箱内物资放入背包，双击已装备外卖卸下到背包。背包内的物资双击不会丢弃。地面外卖优先自动装备或同款同品质合成，装备满且无法合成时收进背包，两处都满则留在地上；地面物资进入背包；外卖可装备/合成、卸下、丢弃，箱中外卖也可直接装备；物资只能携带变卖。背包满时不会消失或吞掉物品。成功撤离仅将实际携带的背包物品与已装备外卖自动换成饭票。阵亡或 6 分钟超时丢失本局收益，永久成长与已有饭票保留。
9. 饭票可购买加厚外卖服（体力）、开局加餐（外卖）和骑手训练（速度），各 3 级。

存档使用浏览器 localStorage，同一访问地址下保留。手机与电脑不共享存档；更换 IP、端口或清除站点数据会使用不同/新的存档。当前是单人原型，敌人为 AI，不包含联机、跨局物品仓库或飞机航线内自由跳伞。

所有角色各自为战，没有敌人友军阵营：奶龙、耄耋以及同类敌人都会互相锁定、绕圈攻击、抵消外卖、击败和抢夺掉落。弱势敌人会逃跑寻找补给，身体碰撞会将重叠角色分开；玩家击杀计数不会计入 NPC 互杀。

## 美术和音效

- 主视觉：内置 image_gen 生成的 `assets/key-art-v2.png`，提示词在 `assets/image-prompt-v2.txt`。
- 游戏角色和物品：程序化 3D 模型。敌人为奶龙与耄耋参考形象。
- 开局点击按钮启用音效，右上角扬声器切换静音。
- 拾取为上扬双音；物品互撞为真实刀剑录音（三种变体、距离衰减、叠音限制），来源和 CC0 授权见 `assets/audio/CREDITS.md`。

## 验证

```sh
npm test
```

使用实际 Three.js 几何和游戏逻辑、模拟 DOM 与渲染器检查：四区出生、建筑阻挡、搜箱、技能选择、撤离开放与中断、单次结算、失败损失、局外购买和存档、超时、跨局重置及连续移动；另验证 NPC 同类互战、抵消、击杀归属、拾取、逃跑、身体分离和受击打断撤离。

已在桌面 Chrome 检查封面、备战室、空投进入地图与暂停；手机真机性能、触控手感和最终数值仍需实测。

五档品质及背包专项检查覆盖：随机箱子数量和类别、逐格揭示、重开不刷物品、隐藏物品不能取走、满包保护、装备满位保护、合成上限、物资无法装备、丢弃和拾取冷却、离开中断搜索、撤离按实际物品结算。

## 箱子外形与搜索时长

| 品质 | 箱子外形 | 容量范围 | 同品质物品逐格搜索时间 |
| --- | --- | --- | --- |
| 普通 / 白 | 白色胶带快递纸箱 | 2–3 格 | 0.65 秒 |
| 稀有 / 蓝 | 金属护角、提手保温箱 | 4–5 格 | 1.6 秒 |
| 史诗 / 紫 | 发光锁轨的宽体设备箱 | 6–7 格 | 3.5 秒 |
| 传说 / 橙 | 圆顶、金色箍带宝箱 | 8–10 格 | 6 秒 |
| 罕见 / 红 | 高身保险柜、封印轮与警示灯 | 11–14 格 | 10 秒 |

时长取决于当前正在搜索的物品品质，箱子内不同品质的物品分别计时，界面显示百分比和剩余秒数。高风险美食广场包含红色箱。小地图的补给箱标记与箱子品质同色。

已验证：开箱过程中连续升级不关闭界面、不清空搜索进度，多次升级依次补选，五类箱子生成对应模型和保底物品，以及红色物品满 10 秒后才揭示。桌面 Chrome 已检查新箱子的地图外观。

箱子容量范围互不重叠：低一档的最大格数严格小于高一档的最小格数。生成后容量和内容在本局固定，反复打开不会重新抽取。
