# 疯狂牛世界

手机端优先的纯 HTML / CSS / JavaScript 海上漂流小游戏。无后端、无 npm 依赖、无 CDN；所有模型、图标、音乐和音效均由项目代码生成，可离线运行。

## 立即运行

直接用现代 Chrome、Edge、Safari 或 Firefox 打开 `index.html`。无需安装或构建。当前只维护这个入口及其 CSS / JavaScript 源码；早期生成的单文件 HTML 和 ZIP 不再更新。

手机访问时，可在本目录运行一个静态文件服务器：

```sh
python3 -m http.server 8080 --bind 0.0.0.0
```

电脑访问 `http://localhost:8080`；同一 Wi-Fi 下的手机访问 `http://电脑的局域网IP:8080`。这只是静态文件服务，没有业务后端。也可以将整个目录上传到任意静态网站托管。

## 操作

- **移动**：左下摇杆支持鼠标与触摸；电脑可用 WASD / 方向键，也可点击场景。
- **收集 / 救牛**：走近海面漂流物自动拾取。右下「一网打捞」或空格提供较大范围打捞，冷却 5 秒。
- **建设**：点击「自定义船形 → 搭建」，选择海面 + 格，再确认铺甲板；也可切换种草、拆甲板。新设施通过「选址」在空闲甲板上放置。面板与搭建模式开启时模拟暂停。
- **船体演进**：建设面板可预览五种船型。升阶后自动返回海面展示约 3 秒改造过程，船壳沿你实际搭建的轮廓生成。
- **任务**：完成后点击左侧任务或进入「任务」领取奖励。
- **暂停**：右上暂停 / P / Esc。静音、暂停状态和家园每 5 秒及关键操作后保存到 localStorage。
- **重开**：暂停菜单 → 重新开始 → 游戏内二次确认。

首次点击后启动声音，这是浏览器的自动播放要求。存档仅保存在当前浏览器和地址中；直接打开文件与通过 HTTP 访问使用不同的存储空间。后台不进行离线收益结算。

## 无限远航版内容

- 5 种资源：金币、青草、木材、牛奶、饲料；宝箱提供组合奖励。
- 9 块起始甲板，最多 81 块；甲板规模等级解锁牛种。另有持续提升的木筏阶数，每阶提高生产加成，并解锁更高设施等级。
- 4 种设施：青草棚、暖暖牛棚、挤奶机、海风奶茶摊。初始上限 5 级，每次木筏升阶将设施上限提高 2 级。
- 6 种牛：初生小牛、踏浪黄牛、云朵白牛、蘑菇怪牛、星夜蓝牛、梦境巨型牛。
- 稀有牛登场的全屏「牛！来！」事件，发现记录与独立模型图鉴。
- 甲板容量、自动生产、缺料等待、救援、稀有种解锁；满员后新伙伴加入同样参与生产的随行牛队。
- 无限海域序号，青草微风海 / 落日沉船湾 / 星乳梦境海 / 金潮宝藏洋四种风貌轮转，分别加成青草、木材、牛奶和金币打捞。
- 高品阶牛：新海域牛的品阶随海域序号提升，救下后强化该牛种的全体产出。
- 无重置远航：完成五项准备后，全部木筏、牛群、建筑、库存和图鉴保留，刷新海上漂流物和本海域目标。
- 丰收暖流、云雀送礼、宝箱潮 3 类随机事件。
- 10 个成长任务，完成后提供可反复领取的漂流委托。
- 程序生成的五声音阶背景音乐、打捞 / 建造 / 救援音效。
- 安全区适配、触摸取消处理、失焦停止移动、弹层键盘焦点约束、本地存档异常恢复。

## 生产规则

初始每 10 秒一轮，每次木筏升阶缩短 0.2 秒，最快 5 秒；只有游戏前台运行时推进。木筏每阶增加 15% 基础产出。每 3 块草地至少产 1 青草，青草棚每级额外产 4 青草。船长保留基础青草产出。伙伴默认分工延续原有收益：初生小牛种草，黄牛、白牛和巨型牛挤奶，蘑菇牛制作饲料，星夜牛经营。可以在「牛群 → 小队调岗」按牛种整队更换工种，新救下的同种伙伴自动加入现有小队，每位伙伴只参与一个工种。挤奶机将饲料转为牛奶，奶茶摊把牛奶转为金币。缺少对应投入时该生产步骤等待，不产生负数资源，也不会失去牛。

每个有成员的工种只在甲板显示一头代表牛，最多六头代表和一位船长。所有成员（含旧存档中的随行牛队）均计入小队人数和生产；代表按品阶优先选择，显示工种与人数，并佩戴工种配色的围裙、帽子或打捞工具。牛棚每级增加 5% 牛群基础产出。旧存档自动补充分工，保留原有牛群、资源、进度和设置。

## 长期成长循环

1. 在「建设」中扩建甲板、升阶木筏并升级设施。升阶费用为当前阶数 × 60 木材、× 45 金币。
2. 点击右上「第 N 海域 · 远航」查看目标：甲板至少 25 块、木筏达到 N+1 阶，本海域打捞 24–42 份物资、救援 2 头牛、建造或升级设施 1 次。
3. 准备就绪后手动出发，资源打捞倍率和漂来牛的品阶随海域序号增长。
4. 在新的风貌和资源加成下继续救援、建设、升阶、远航。海域没有设计上的通关终点；四种美术风貌轮转，并非无限种独立美术内容。

原始十个成长任务继续保留，之后的循环委托奖励也随海域提高。地图保持 81 块上限以保证手机操作空间；长期成长来自阶数、设施、牛队和远航。库存使用数值安全上限 10^12，避免数值溢出。

旧 version 1 存档自动迁移至 version 2，沿用原本 localStorage 键，不清空资源、木筏、牛、设施、任务和声音设置。

## 从木排到海上避难所

| 木筏阶数 | 外观阶段 | 看得见的变化 |
| --- | --- | --- |
| 1 | 漂流木排 | 裸露木板、横梁和绑绳 |
| 2 | 加固木筏 | 加厚浮筒、包边、安全护栏 |
| 3–4 | 牧场帆船 | 整体船壳、尖船头、桅杆与布帆 |
| 5–7 | 远航避难船 | 深船壳、舷窗、驾驶舱、救生设备 |
| 8 及以上 | 海上方舟 | 双层船楼、灯塔、太阳能顶棚 |

8 阶后仍可继续强化生产和设施，但不继续增加无限层模型。船头和上层船楼为自动适配轮廓的外观结构，可行走区域仍由甲板格决定。

搭建区域为 9 × 9 网格，每块新增甲板必须与已有甲板共边。可以搭成长条、L 形、环形或带分支的平台；点击移动会沿连通甲板寻找路径。拆除保留至少 9 块甲板，不允许拆除中央龙骨、玩家脚下、设施占用格和会导致断开的通路。可拆格回收一半实际建造木材；旧存档中没有费用记录的格子不返还木材。现有设施仍可原地升级，新设施支持选址；本版不提供已建设施搬迁。


点击牛身会定位到该牛脚下的甲板；遮挡主角的牛和设施自动淡化，主角带有「你」标记并保持可见。牛群会主动让出身边空间，不参与主角碰撞。点击目的地有落点标记，再次点击可立即改变路线。测试包含密集巨型牛群中点击移动、重新指定目标和主角可见性。


主角与牛群模型随实际移动方向平滑转身，停止时保留朝向。点击寻路先检查甲板是否能直线通行，仅在缺口处绕行，并移除不必要的格心节点；路线按 2.4 格/秒连续跟随，不在每格中心减速或停一帧。到达终点精确停止，再次点击立即改道。新增测试覆盖 30/60/120 FPS 行进速度、凹形甲板绕行和模型朝向旋转。

## 工种与调岗

- 打捞员：每轮每位成员打捞一份现有漂流物，可救牛，每轮最多三份。
- 种植员：每位成员每轮基础产出 2 青草。
- 饲料员：每位成员每轮基础产出 2 饲料。
- 挤奶员：每位成员消耗 1 青草，基础产出 2 牛奶；白牛为 3，巨型牛为 10。青草不足时仅供应有草的成员。
- 店员：每位成员每轮基础产出 5 金币。
- 建造员：每位成员每轮基础产出 1 木材；成员数量乘品阶每单位降低 3% 建造木材费用，最高 30%，适用于甲板扩建、木筏升阶和设施建设升级。

生产资源受木筏、品阶、牛棚加成；自动打捞数量不受倍率加成，物资数量仍遵循当前海域规则。调岗不消耗资源，下一轮起按新工种生产。相同工种的不同牛种共用一头代表，船长不参与调岗。
