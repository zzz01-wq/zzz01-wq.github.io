# 疯狂牛世界

手机端优先的纯 HTML / CSS / JavaScript 海上漂流小游戏。无后端、无 npm 依赖、无 CDN；所有模型、图标、音乐和音效均由项目代码生成，可离线运行。

## 立即运行

直接用现代 Chrome、Edge、Safari 或 Firefox 打开 `疯狂牛世界.html`（单文件版）或 `index.html`（源码版）。无需安装或构建。单文件版也可独立复制给别人。

手机访问时，可在本目录运行一个静态文件服务器：

```sh
python3 -m http.server 8080 --bind 0.0.0.0
```

电脑访问 `http://localhost:8080`；同一 Wi-Fi 下的手机访问 `http://电脑的局域网IP:8080`。这只是静态文件服务，没有业务后端。也可以将整个目录上传到任意静态网站托管。

## 操作

- **移动**：左下摇杆支持鼠标与触摸；电脑可用 WASD / 方向键，也可点击场景。
- **收集 / 救牛**：走近海面漂流物自动拾取。右下「一网打捞」或空格提供较大范围打捞，冷却 5 秒。
- **建设**：扩建木筏、铺草、建造和升级设施；自动选择位置。面板开启时模拟暂停。
- **任务**：完成后点击左侧任务或进入「任务」领取奖励。
- **暂停**：右上暂停 / P / Esc。静音、暂停状态和家园每 5 秒及关键操作后保存到 localStorage。
- **重开**：暂停菜单 → 重新开始 → 游戏内二次确认。

首次点击后启动声音，这是浏览器的自动播放要求。存档仅保存在当前浏览器和地址中；直接打开文件与通过 HTTP 访问使用不同的存储空间。后台不进行离线收益结算。

## 第一版内容

- 5 种资源：金币、青草、木材、牛奶、饲料；宝箱提供组合奖励。
- 9 块起始木筏，最多 81 块；每扩建 6 块提升家园等级，最高 5 级。
- 4 种设施，各 5 级：青草棚、暖暖牛棚、挤奶机、海风奶茶摊。
- 6 种牛：初生小牛、踏浪黄牛、云朵白牛、蘑菇怪牛、星夜蓝牛、梦境巨型牛。
- 稀有牛登场的全屏「牛！来！」事件，发现记录与独立模型图鉴。
- 牛群容量、自动生产、缺料等待、救援、稀有种解锁。
- 丰收暖流、云雀送礼、宝箱潮 3 类随机事件。
- 10 个成长任务，完成后提供可反复领取的漂流委托。
- 程序生成的五声音阶背景音乐、打捞 / 建造 / 救援音效。
- 安全区适配、触摸取消处理、失焦停止移动、弹层键盘焦点约束、本地存档异常恢复。

## 生产规则

每 10 秒一轮，只有游戏前台运行时推进。每 3 块草地至少产 1 青草，青草棚每级额外产 4 青草。初生小牛产青草；黄牛和白牛消耗青草产奶；蘑菇牛产饲料；星夜牛产金币；巨型牛产大量牛奶。挤奶机将饲料转为牛奶，奶茶摊把牛奶转为金币。缺少对应投入时该生产步骤等待，不产生负数资源，也不会失去牛。

容量 = 3 + floor((木筏数 - 9) / 3) + 牛棚等级 × 4。容量不足时牛继续在海上等待，扩建后可再救援。

## 资源与代码结构

```text
疯狂牛世界/
├── 疯狂牛世界.html          # 可独立分发的离线单文件版
├── tools/bundle.py         # 修改源码后运行 python3 tools/bundle.py 重新打包
├── index.html              # 单页入口与可访问 UI
├── style.css               # 手机优先适配、HUD、面板与事件动画
├── js/
│   ├── core.js             # 纯模拟：资源、扩建、牛群、生产、任务、存档校验
│   ├── render.js           # 原创低多边形模型与 Canvas 正交 3D 投影
│   └── game.js             # 输入、UI、存档、音频及游戏主循环
├── assets/
│   └── icon.svg            # 原创矢量网页图标
├── tests/
│   └── core.test.cjs       # Node 内置测试：10 项模拟与完整进程验收
├── VISUAL_REFERENCES.md    # 公开参考链接、提取方向和原创资源说明
└── README.md
```

角色并非贴图：`render.js` 通过三维顶点、低面数椭球、立方体与锥体组合模型，逐面明暗着色，再以正交微斜角投影到 Canvas 2D。不依赖 WebGL 或外部 3D 库。`game.js` 中的 SVG 图标与 Web Audio 合成音频均为内嵌程序资源，所以无需额外模型、贴图和音频文件。

## 检查

```sh
node --check js/core.js
node --check js/render.js
node --check js/game.js
node --test tests/core.test.cjs
```

测试覆盖自动收集、防重复冷却、扩建连通性与上限、费用与解锁、满员救援、生产收支、暂停与存档恢复、非法存档回退、移动边界、30/60/120 FPS 与慢速摇杆跨格移动、旧存档扩建区域通行，以及不注入资源完成巨型牛和全部任务的完整模拟。

## 扩展位置

牛种与产出、任务和建筑成本：`js/core.js`。角色和设施造型：`js/render.js`。UI 与音乐：`js/game.js`、`style.css`。
