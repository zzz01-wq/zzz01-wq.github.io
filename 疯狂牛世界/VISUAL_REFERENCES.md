## 本项目的转译

视觉主张：雾青海面上的一块草地与一个土黄色小生命，用简单几何、粗分面和略不自然的直立比例，形成天真、安静而有点荒诞的海上白日梦。

画面层次：全屏海面 → 居中的木筏与小牛 → 周围持续漂来的物资 → 克制的资源栏、成长任务与底部功能入口。没有另设网页式宣传首页。

交互方向：缓慢流动的海面与摇晃资源、略笨拙的牛群起伏、打捞扩散波纹与资源浮字，以及稀有牛的夸张全屏登场。

所有牛、木筏、设施、漂流物、海面、图标与声音都由本项目的原创程序几何 / SVG / Web Audio 构建。项目不打包、热链或展示电影剧照、海报、角色模型、原声及二创素材。参考图片只用于识别美术方向。
