# 荒城 · The Quiet After

一个可运行的桌面浏览器 3D 第一人称末日生存沙盒原型。没有主线、关卡或通关条件；与阿灰一起搜刮，把物资带回据点，死亡后靠储备重新开始。

## 运行

需要 Node.js 20.19+ 或 22.12+，以及支持 WebGL 2、鼠标锁定的桌面 Chrome / Edge / Firefox。

```bash
npm install
npm run dev
```

打开终端显示的本地地址（默认 http://127.0.0.1:5173），点击「进入荒城」。首次启动需要点击页面授权鼠标捕获；按 Esc 释放鼠标并暂停。依赖安装后运行无需联网，字体和模型不会从外部网站实时加载。

```bash
npm test          # 生存规则测试
npm run build    # 打包到 dist/
npm run preview  # 本地运行打包版本
```

浏览器集成测试需要开发服务器已运行。默认使用 macOS 的 Google Chrome；其他平台通过 `CHROME_PATH` 指定 Chromium / Chrome 可执行文件：

```bash
npm run test:e2e
# CHROME_PATH=/path/to/chrome npm run test:e2e
```

## 操作

| 输入 | 操作 |
| --- | --- |
| WASD / 鼠标 | 移动 / 观察 |
| Shift / C / Space | 冲刺 / 按住蹲下 / 跳跃 |
| 左键 / 右键 | 攻击 / 按住瞄准 |
| R / V | 换弹 / 缠线球棒近战 |
| 1 / 2 / 3 / 4 | 缠线球棒 / 手枪 / 猎枪 / 步枪 |
| E | 对准近处物体互动 |
| Q | 让阿灰搜索，40 秒冷却 |
| F | 手电开关，消耗电池 |
| Tab / M | 背包 / 地图 |
| Esc | 暂停，导出／导入存档 |

背包、地图和暂停菜单打开后模拟暂停。窗口失焦也会暂停。

## 从哪里开始

出生在旧加油站雨棚附近。站房入口在南侧，绕到站房后方即可进入。保险柜里有一把未装弹手枪和 18 发子弹；它们是首次世界初始化的储备，死亡不会补发。取出、装备、按 R 装弹，即可使用。也可以只带缠线球棒探索。

向北是小镇和超市，继续向北可到诊所、警局、医院；西边是农场和森林，东北是工业区。按 M 看地图。各建筑从朝南的门口进入，对准箱子、柜子或货架按 E 搜索。拿到珍贵物资后，回家存入保险柜。

工作台支持武器维修、布料制作绷带、消耗燃料净水和烹饪；床可以用饥饿、口渴换取休息恢复。背包可以喂狗、治疗狗、使用药品和装备护甲。

## 已实现的循环

- 约 224 × 224 米的可探索区域，9 个地标区、11 栋可进入建筑，汽车、货架、医疗柜、工具箱、植被、路灯与家具。
- 第一人称碰撞、冲刺、蹲下、跳跃、瞄准；可见双臂、手指握持、后坐力与换弹动作；近战、手枪、双管猎枪、步枪和低概率精密步枪；弹种、装弹、射速、后坐力、耐久和维修。
- 生命、饱腹、水分、体力、出血、感染、雨淋降温；装备护甲、背包格数和负重影响。正常饱腹约 67 分钟从满值耗尽，水分约 44 分钟；一份食物约可支撑 25 分钟，净水约 18 分钟。
- 按地点随机资源池，四档稀有度。容器离玩家超过 35 米并至少 5 分钟未接近后，才有概率刷新，未刷新则稍后再尝试。
- 感染者闲逛、视野判断、听觉、枪声吸引、追击、攻击、沿最后位置搜索及失去目标；建筑遮挡射线；网格寻路绕开墙壁。死亡的感染者 5 分钟后在玩家远离时补充。
- 阿灰自然跟随、停下嗅闻、搜索物资、竖耳低吼和吠叫、近距离攻击；饥饿与受伤，重伤后无法战斗但不会永久死亡；回据点逐渐恢复。
- 据点保险柜、储物箱、床、工作台、狗窝、地图和收音机；保险柜 20 → 40 → 60 → 100 格升级。
- 死亡丢失全部随身物资、护甲与背包升级；尸体保留 15 分钟模拟时间，装备部分受损；随机外围出生，只有基础工具、少量水和食物；据点储存保留。
- 昼夜一周约 40 分钟；晴、阴、雨、暴雨、雾；手电耗电，雨影响听觉、温度和速度。随机远处枪声、雷雨、遗落物资和短波信号。
- 每 10 秒和关键物品操作后自动本地保存，刷新可继续；存档 JSON 导出与校验导入。

## 存档说明

存档保存在当前浏览器、当前网站来源的 localStorage，键为 `huangcheng.save.v1`。切换浏览器、端口、隐私窗口或清除网站数据不会共享存档；迁移前从暂停菜单导出 JSON。没有云存档、后端或账号。

保险柜和据点储物箱都会跨死亡保留，容量分别受限。尸体、掉落物、已搜容器和世界生存状态也会保存。感染者的位置与临时追踪、狗的临时搜索目标不保存，刷新后重新生成。离线期间不推进时间。开发环境热更新会重新加载页面并读取最近一次存档。

## 原型范围

这是完整可玩的核心循环 Demo，采用 CC BY 3.0 授权的 Rosswet Mobile 感染者、CC0 授权的 Quaternius 动物／武器／道具／植被模型、wriks 第一人称手臂与合成环境音。当前美术偏风格化，建筑主体仍为原型模型；尚未包含动作捕捉、真实弹道／弹丸散射、多人联机、复杂物理、完整建造系统或移动端触屏控制。猎枪使用近距离高伤害射线模拟；环境温度与疾病是简化模型。后续可保留数据层替换为正式美术和动画资源。

所有数值、区域和物品定义位于 `src/core.js`，场景及寻路在 `src/world.js`，第三方模型加载在 `src/assets.js`，第一人称骨骼与持械在 `src/viewmodel.js`，输入、AI 和界面在 `src/main.js`，声音在 `src/audio.js`。
